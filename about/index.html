About

Who am I?

I’m Victor Schumann Macário, a programmer from Brazil and currently living and working in Portugal. I decided to start this blog since I was having some stubborn ideas after reading some books, and wanted to write about them. This blog is my personal notebook of things that I would like to write, remember or share.

I did try to write a blog before, with SEO strategies, ad revenue, niche focused… and I posted every day. I did not move on with that project. It was not only exhausting, but it also did not fulfill me. So, here I am, a couple of years later, starting fresh. I believe that if you enjoy the ride, you will stay, and there is no rush.

Who is Hugo?

I created this blog with Hugo, Github, and a domain under my name. I really enjoyed it, and despite being a programmer for a living, I believe anyone can do it in a couple of days’ work and research.

Written in Go, Hugo is an open source static site generator available under the Apache Licence 2.0. Hugo supports TOML, YAML and JSON data file types, Markdown and HTML content files and uses shortcodes to add rich content. Other notable features are taxonomies, multilingual mode, image processing, custom output formats, HTML/CSS/JS minification and support for Sass SCSS workflows.

Hugo (and this blog) makes use of a variety of open source projects including:

  • https://github.com/yuin/goldmark
  • https://github.com/alecthomas/chroma
  • https://github.com/muesli/smartcrop
  • https://github.com/spf13/cobra
  • https://github.com/spf13/viper
  • https://github.com/nanxiaobei/hugo-paper
